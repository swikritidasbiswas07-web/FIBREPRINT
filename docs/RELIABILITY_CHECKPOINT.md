# FIBREPRINT v0.20 — Reliability checkpoint

## Purpose

Investigate how wide an error band must be to cover held-out study observations, especially the highest-release fabrics. This is **not** model deployment and **not** a formal conformal prediction interval.

## Install (only one new Python script)

Place `check_prediction_reliability.py` in `FIBREPRINT/backend/`. Leave the existing backend, frontend and original workbook unchanged.

The script expects these existing files in `FIBREPRINT/backend/data/`:

- `vassilenko_surface_comparison_oof.csv` (generated by v0.17, with `ridge_plus_description_keywords_prediction` and original Random Forest predictions)
- `vassilenko_source_alignment.json` (generated by v0.19, status `STRUCTURAL_AUDIT_PASS`)

If they are currently only on your computer elsewhere, copy them into `backend/data/`, retaining their exact names.

From PowerShell in `FIBREPRINT/backend/`:

```powershell
.venv\Scripts\python.exe check_prediction_reliability.py --oof data/vassilenko_surface_comparison_oof.csv --audit data/vassilenko_source_alignment.json
```

Outputs:

- `data/vassilenko_reliability.json`: overall diagnostic and per-wash, measured-target-bin and per-fabric results
- `data/vassilenko_reliability_by_observation.csv`: individual out-of-fold predictions, error bands and coverage

## Methodology

For each specimen, compute the 90th percentile of *absolute prediction errors of other specimens*. Use that error magnitude on both sides of the specimen's original held-out Ridge prediction; clip the lower bound at zero, since negative fibre-release mass is not meaningful. Assess observed coverage overall, by wash, by measured-release groups and by fabric. A wash-specific diagnostic cutoff is also reported when enough calibration fabrics are available; the main reported band always uses the global cutoff.

The source workbook's checksum and structural audit status are carried forward. The audit checker verifies mass-cell alignment but does not validate every feature or the original study's protocol.

## Important statistical limitations

- **Not a confidence or prediction interval:** residual sets originate from a 5-fold grouped out-of-fold exercise; although each prediction holds out its own fabric, model training folds can overlap other fabrics in the residual cutoff. This is not independent split calibration and provides no finite-sample coverage guarantee.
- Every wash from one fabric is correlated with its other washes; the 155 rows are not 155 independent materials.
- The 90th percentile is descriptive, not a calibrated 90% coverage statement for new textiles.
- Stratifying on **observed** release (for example, >=400 mg/kg) is for post-hoc diagnostics only. A model cannot know the true release in advance to decide which category a future material occupies.
- An error band can be so broad that it is scientifically unhelpful; both **coverage and width** must be inspected.
- The dataset remains single-study and research-only; external studies and independently calibrated model development are future work.
- No public numerical predictions are enabled by this file.
